# Customer-Segmentation-Project
Here are both files:
customer_segmentation_dashboard.html — a fully self-contained interactive dashboard (dark theme, 5 tabs: Cluster map, Segment profiles, Purchase behavior, Insights, Python code with syntax highlighting + copy button). Open it in any browser — no server needed.
customer_segmentation.py — the complete scikit-learn pipeline. To run it:
bash
pip install scikit-learn pandas matplotlib numpy
python customer_segmentation.py
